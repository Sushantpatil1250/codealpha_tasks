# 🎓 Student Grade Tracker

## 📖 Description

Student Grade Tracker is a Java Swing based desktop application that helps manage student records and academic performance. The system allows users to add student details, calculate grades, and generate performance reports through a simple graphical interface.

---

## ✨ Features

- ✅ Add Students
- ✅ Delete Students
- ✅ Generate Report
- ✅ Calculate Average Marks
- ✅ Find Highest Marks
- ✅ Find Lowest Marks
- ✅ Top Performer Identification
- ✅ Grade Calculation
- ✅ Save Report to File
- ✅ User-Friendly GUI

---

## 📊 Grade System

| Marks Range | Grade |
|------------|--------|
| 90 - 100 | A+ |
| 80 - 89 | A |
| 70 - 79 | B+ |
| 60 - 69 | B |
| 50 - 59 | C |
| Below 50 | Fail |

## 🚀 How to Run

1. Open the project in IntelliJ IDEA.
2. Compile all Java files.
3. Run `StudentGradeTracker.java`.
4. Add student records and generate reports.
