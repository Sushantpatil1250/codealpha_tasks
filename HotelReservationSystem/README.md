# 🏨 Hotel Reservation System

## 📖 Description

Hotel Reservation System is a Java Swing based desktop application that helps manage hotel room bookings efficiently. Users can book rooms, check out customers, delete reservations, and track room availability through an interactive graphical user interface.

---

## ✨ Features

- ✅ Book Rooms
- ✅ Check Out Customers
- ✅ Delete Reservations
- ✅ Clear All Reservations
- ✅ Room Number Validation (1-20)
- ✅ Prevent Duplicate Room Booking
- ✅ Room Type Selection
- ✅ Room Pricing System
- ✅ Occupancy Rate Calculation
- ✅ Hotel Summary Dashboard
- ✅ User-Friendly GUI
